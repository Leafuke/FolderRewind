# 世界预览修复：API 3.9 / MineRewind 1.9.8

## 实现

- 解压与 NBT 格式错误在区块边界转换为 Corrupt；访问错误为 Unavailable；变化中的文件为 Changing。临时区块失败采用 500ms、1500ms 两次自动重试，最终错误提示刷新。取消继续传播。
- Render 返回 `IsFinal=false` 时，宿主保留当前图像，至少 100ms 后再请求；最多四个请求，初始画面优先，细化任务轮转。单次最多处理 64 个待解码区块，并在 50ms 软预算后的区块边界让出。
- region header 和校验后的区块区间复用；同区块并发读取共用在途结果。紧凑颜色、高度和有效像素摘要提供 1/2/4/8/16 方块每像素的面积聚合缩略图。完成的部分保存于瓦片进度中，摘要淘汰不导致整张瓦片重头开始。
- 邻区块到达后重算相邻阴影；相邻瓦片完成后宿主触发一次边界重绘。远景只聚合已有摘要和占用索引，不主动解码整个远景。缩放时旧图保留至新结果完成。
- 插件地表、摘要、索引和进度统一受 128MiB 预算约束；宿主位图预算 64MiB。预算不包含世界目录索引、在途分配、图形资源或整个进程工作集。
- 修复右方向键、相机 LRU、最后活动维度；新增合法坐标范围、越界错误、未生成提示、比例尺和直接返回世界范围入口。高度使用 provider 标签，明确扫描上限与洞穴模式的区别。

## 本地化根因

原有 `I18n.PickBest` 会在当前英文没有字典条目时，先命中中文翻译，再考虑英文 Default。现在只匹配有效语言及同语言别名，随后优先 Default，再回退英文或确定性条目。

界面验收另外发现：未打包版仅给自定义资源加载器设置语言，XAML x:Uid 仍取系统语言。现在通过 `Microsoft.Windows.Globalization.ApplicationLanguages.PrimaryLanguageOverride` 同步 MRT Core，再设置 .NET culture 与资源加载器。保留现有语言设置的生效时机。

预览工具栏、导航、详情、诊断、高度说明及无障碍名称采用中英文文本；维度名称本地化，原始维度 ID 在详情中保留。用户命名、UUID 和方块/群系资源 ID 不翻译。

## 构建

在宿主仓库运行：

```powershell
pwsh -NoProfile -File scripts/Build-WorldPreview.ps1
```

脚本按 Abstractions 源文件、项目文件和说明文档的内容生成 `3.9.0-preview.b<hash>`；已存在的同身份包不覆盖。独立 feed/cache 为 `artifacts/preview39-feed` 与 `artifacts/preview39-packages`。候选 API 未发布到 NuGet，插件单仓库恢复前需提供该本地 feed 或由此入口协调构建。

默认运行插件全量、API 全量、Runtime 全量以及宿主预览/语言/无障碍定向测试；`-FullHostTests` 改为宿主全量测试；`-SkipHostBuild` 可仅验证并更新插件包。脚本校验 manifest、领域程序集及禁止捆绑 Abstractions DLL，再更新内置 `.frplugin` 和 SHA256。

## 已执行验证

- MineRewind：93 项通过，包括异常隔离、压缩损坏、NBT 超限、文件占用恢复、共享解码、面积聚合、远景零主动解码、缓存压力与取消。
- Abstractions：15 项通过，公共 API 快照增加 CoordinateBounds、IsFinal；默认 IsFinal 保持旧 provider 行为。
- Runtime：146 项通过，冻结输出保留 IsFinal，合法坐标范围可选且经过边界校验。
- 宿主定向：49 项通过，涵盖语言、资源完整性、方向、相机 LRU、坐标和比例尺。
- 宿主全量：807 项通过。
- WinUI x64 Debug 的打包与 MSI/非打包构建通过。实际隔离窗口验证了 MSI/非打包与 MSIX 两种发行形态的中英文预览文本、彩色地形和渐进状态；验证了英文越界坐标提示、中文高度说明。临时 MSIX 注册及测试进程已清理，用户原有安装未改动。
- 合成压力场景：1024 个已生成区块、8 方块每像素、1MiB 插件缓存。最新一次首个结果 59ms、完整瓦片 329ms、暖缓存 12ms、解码 1024 次、缓存 1,044,616 字节；暖缓存不增加解码。50ms 为区块边界软预算，首个结果含初始化及组图开销。

上述性能来自合成单 section 数据和本机磁盘缓存，不是与旧版对照的真实大世界基准。真实玩家大世界、长期拖动的 p95 延迟及进程存活内存曲线仍需要实际数据验收；不能以单元测试、工作集瞬时变化或合成数字替代这些结论。
