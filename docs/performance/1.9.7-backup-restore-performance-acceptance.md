## 设置、证据与兼容

新建项目/预设备份 Balanced、还原 Balanced、Quick Safety Snapshot=true。旧 JSON 的 VerifyArchiveBeforeRestore=true 或缺失迁移还原 Strict；false 迁移 Balanced。新字段优先且不受 JSON 顺序影响；非法枚举、类型或 null 拒绝。缺失整个 Archive 节也走旧输入迁移。复制/草稿/源生成序列化保留新策略。

SafeRestoreEnabled 仅为旧输入兼容别名，导出恒 true，不关闭事务回滚。VerifyArchiveBeforeRestore 的导出由新还原策略决定。普通恢复点使用 BackupBeforeRestore，Quick 使用独立的新开关，互不 OR。NoChanges 不创建恢复点；用户关闭恢复点也不关闭回滚。

VerifiedFinal 表示按入库策略验证完成。Balanced 清单不冒称内容深测；只有实际 Strict/显式 Deep 才产生 DeepVerification/Verified 深度证据。storageSha256 存在时必须验证真实载荷，仅在本次受保护对象内复用。所需内容损坏/错误密码在目标修改前失败；未选择条目的损坏若无存储摘要，Balanced 可仅保证本次选中数据，Strict 会拒绝，已有真实损坏用例。

Smart 不支持的链、空目录、目录/文件过渡和不明确语义顺序 fallback。7-Zip 实测 @listfile 裁掉行首空白，此类合法名字使用顺序路线并保持原名。删除最后一个文件但保留空父目录也 fallback。目录项、重复/大小写冲突、ADS/链接和危险路径不以 trim 或忽略掩盖。

## 方法与原始记录

原始 JSON/TRX、冻结源码和二进制都在本地忽略的 `D:/Programs/FolderRewind/Reference/performance/`。不提交世界、配置、归档或凭据。基线副本仅加计时/计数和隔离测试入口，没有移植候选行为。基准每个有效组合 3 次，原始 repeat=0 首轮保留；冷缓存未控制，没有 P95，没有内核 I/O 精确计数声明。

B1/B5：固定 Random(719) 的 2 GiB 混合压缩性合成文件 + 1000 小文件，C/D、Clean/Overwrite 各三次。Archive/目标输入在每轮重置，计时后验证文件树内容。服务调用计时不包含语料构造或正确性摘要读取，也不包含 UI。B2：8 MiB 文件反复覆盖的六层链。B3：8 MiB 边界外锁文件，按身份核对保留。B4：组件探测与另行实际 Host Quick 四组合。Host 工具初始化 XAML 调度队列，调用生产备份/Quick 服务而不创建窗口；启动前拒绝用户配置路径回落。

真实世界：从已授权的存档读取并持有受管理输入保护后制作未扩大副本，127 个受管理文件、161,899,956 字节；原世界另有 3 字节 session.lock 被默认插件策略排除。还原目标另放 16 MiB 边界外缓存，验证过滤 Clean/Overwrite 及保留身份。此规模不是 2 GiB 大世界。

临时首轮发现 FileDelta 重演整份位置表、重复祖先/父目录打开导致退化，已改为增量位置表与持续父目录保护后复测。保留先前原始结果以便审计，不挑最快一轮冒充中位数。

## 恢复与支持范围

普通 Restore/Quick/Checkout 支持本机 NTFS、已有目标父目录及可取得所需访问权限。网络卷、卷根、重解析路径、受影响硬链接/ADS、重叠目标、模糊别名和空间不足在修改目标前阻断，不偷偷转至软件卷。完整目录交换保留根 ACL/属性；新发布文件/目录恢复目标权限继承，容器的私人权限不带入目标。

Preparing 先登记容器；物化/补丁全部完成后保存不可变计划与 SHA-256，再登记 Prepared 才移动。进度最多 64 动作/Source 边界刷新，缺失进度从物理身份判定；仅明确末尾半条记录可忽略。Workspace 精确匹配 Expected 则逆序回滚；Desired 已持久则正向处理。Merge 以原 Pack bytes durable 为权威。未知对象或状态保全，绝不按 `.folderrewind-*` 名字递归接管/删除。

提交前和 Workspace 保存后复查受管理集合。外部新增路径在提交前触发回滚，提交后报告 CommittedRecoveryRequired 并保留 rollback；清理失败报告已提交警告。部分解压/容器登记窗口中无法证明成员归属时保留现场，需要恢复，不为方便清理猜测归属。用户应关闭写入程序或使用插件协调；不承诺任意同用户恶意篡改或底层断电损坏。

旧二进制不认识未完成 v2 事务。降级前必须完成/明确处置还原事务及 Held 云任务，完整保全载荷、T/S/R 和日志；Git 回退不等于数据可安全降级。无未完成事务时历史/公共插件协议未升级，旧版会执行更保守检查且不认识 Quick 的关闭选项。
