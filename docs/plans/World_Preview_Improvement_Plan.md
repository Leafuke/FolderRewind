按用户要求，不运行 `dotnet test`、UI 自动化或性能基准。执行相关 restore/build/pack、源码审查与包清单/摘要检查；不得把构建通过描述为实际 UI 验收通过。

人工验收待用户执行：

- 高度输入负数、清空重输、回车、失焦、Escape、滑块松手，确认仅提交合法整数且不丢失相机。

- 原有版本及 26.2/26.3、新方块/群系、混合 DataVersion、内嵌/外置 LZ4。
- 未解码、无记录、无表面、不支持、损坏、缺色和部分备份空白不会混淆。
- 普通、增量、语义、加密及部分历史；取消、空间不足、刷新、退出重开与失效临时目录回收。
