## 已实现的操作流程

在高级历史的单文件夹视图选择来源分支，通过“合并分支”进入原生 WinUI 工作页。目标为该文件夹的活动分支；分析后固定双方历史身份。来源分支不移动，其他文件夹不随之切换。历史页同时提供未完成合并入口。

页面依次承载分析、冲突处理、生成并审阅结果、应用和恢复。来源与已有任务放在可展开区域；当前文件夹、分支方向和目标路径持续显示。返回历史恢复原来的筛选及浏览位置。既有会话继续使用原 SQLite 存储，不重置数据库或改变历史仓库格式。

冲突列表按路径排序，支持搜索、未解决/已解决/自动处理筛选、增量加载、批量勾选、清除决定和撤销最近一批。没有勾选时，采用一侧只操作当前查看的冲突；有勾选时，只操作已勾选项目。决定成功写入后才显示已保存。写入失败保留未保存提示及重试入口；放弃任务前确认将清理的人工成果。

只读文本比较使用 DiffPlex 1.9.0，提供双方行号、变更标记和同步滚动，共同基点按需展开。支持严格 UTF-8，以及带 BOM 的 UTF-8/UTF-16；每侧最多读取 512 KiB、展示 5,000 行，超限明确说明截断且不进行完整差异计算。二进制或不支持的编码展示元数据；缺失文件与空文件分开表达；路径结构和来源范围冲突按组决定。不会改写预览文件的编码或换行。本轮不提供内嵌编辑器、文本自动合并或游戏格式语义验证。

内容宽度达到 1,000 DIP 时显示列表和双栏比较；720–999 DIP 使用紧凑列表与上下比较；更窄时切换列表和详情。列表宽度、筛选、选中文件及浏览位置保存在独立本机展示状态中，损坏时使用默认值。

## 任务、审阅与安全边界

- 合并操作由应用级服务持有，页面只订阅状态。离开页面不取消任务，同一配置只执行一个合并操作；人工处理期间不长期占用配置写锁。
- 停止在准备、生成及提交前校验阶段有效；进入保护与目标修改阶段后完成原事务，不再任意取消。正常退出请求停止可取消阶段，并等待活动合并；沿用现有 30 秒超时策略，超时取消退出而非强行终止。
- “生成并审阅结果”完成归档与内容验证，分别列出相对目标分支的变化、相对当前目录的实际写入，并显示是否需要保护快照。下载量和空间需求未知时明确显示未知。
- 提交复核候选 Pack/Transaction 身份、计划和决定修订号、双方分支头、配置及工作目录存在状态/内容指纹。过期时阻断并要求重新审阅，不静默更换候选结果。
- 业务结果先保留，随后刷新会话；刷新失败不覆盖已经提交的事实。提交前回滚、需要恢复、已提交但需恢复、提交后警告使用不同结果。恢复沿用原事务，重启后的事实以历史 Pack 和事务日志为准。
- 完成页可定位合并版本，并进入已有保护快照管理流程。重新分析只继承输入签名仍匹配的决定，并显示保留与失效数量。

## 用户人工验收清单（全部待执行）

使用独立测试配置、测试存档及备份目录，避免把实验操作施加到正式存档。下列复杂交互不以自动测试或构建通过替代。

- [ ] 无需合并、快进、双方独立修改：结果正确，来源分支不移动，其他文件夹及活动分支保持原状。
- [ ] 文本双方修改、修改/删除、空文件、二进制、大小写及文件/目录结构冲突：对象与操作后果清楚，整组处理正确。
- [ ] UTF-8、UTF-16、超限文本和长路径：预览与限制提示正确；没有编码转换或静默截断后写回。
- [ ] 超过 100 项冲突：滚动加载、搜索、过滤、勾选、批量采用、清除、撤销和下一项导航可用；刷新不丢当前位置。
- [ ] 导入解决文件：只对支持的单文件冲突开放；决定已保存后重进任务仍存在；保存失败可重试。
- [ ] 离开页面、返回历史、切换到其他页面再进入：不重复执行任务，历史筛选和位置恢复，页面没有挂起状态残留。
- [ ] 下载/生成中停止：保留有效成果；保护/写入时不能强行取消；退出等待和超时提示符合实际任务状态。
- [ ] 当前目录有未备份修改：审阅能看到实际覆盖/删除，合并前快照可实际还原；文件级验证不被表述为游戏格式验证。
- [ ] 审阅后新备份、修改目录或配置：旧审阅被阻断，重新分析/审阅后方可提交。
- [ ] 下载失败、损坏归档、文件占用、提交后刷新失败：状态准确、下一步明确，已提交不会显示为未提交。
- [ ] 使用测试副本模拟中断并重启：沿用原事务恢复，没有重复合并版本；复原后仍可精确还原合并结果。
- [ ] 中英文、深浅主题、高对比度、100%/150%/200% DPI、窄窗口、键盘和读屏：重要内容、焦点、操作及阶段播报可用。

只有用户完成这些条目后，才能把桌面交互和复杂恢复流程标为已验收。
