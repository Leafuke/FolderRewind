# 文件夹拥有独立分支，备份批次只记录操作结果

一个备份项目可以收纳彼此独立的存档及共享环境。项目级分支要求全部来源具有完整基线，并可能在切换一个存档时还原其他来源，与独立存档演进的用途不符。因此分支、语义检查点和活动分支归属单个 Source；项目继续管理规则、自动化和一个共享仓库。批次记录本次参与来源的结果及当时分支，不拥有统一分支。

SourceCheckpoint parents 表达分支历史延续，SourceVersion parents 表达内容来源，两者分别保留。普通还原不切换分支；多来源批次还原使用一个事务但保持各自分支。检出、合并及快速还原均显式限定来源，未参与的来源不会因缺少基线阻止另一个存档建立 main。

本次取舍放弃项目统一分支及来源名单三方合并，不并行维护两套模式。未发布的 1.9.x 元数据通过维护工具归档后重新建立，不提供旧开发版格式转换；配置、来源文件及实际备份归档保留。ADR 0006 的不可变事实、集合同步、精确物化及事务恢复原则继续适用，配置级分支和检查点部分由本决策替代。
