# 空间预览需求协议（API 3.18）

空间预览只提供只读栅格及诊断。需求、统计和缓存不能授权备份遗漏、恢复、删除或完整性通过。Host 管理调用生命周期；提供者管理领域读取、共享工作和内存预算。

## 能力与身份

所有空间预览提供者必须实现 `ISpatialPreviewDemandCapability`，同时声明 API minor 至少 18。该接口继承原预览接口，并增加无默认实现的 `UpdateDemandAsync`。保留原接口的二进制定义；新 Runtime 在激活时拒绝缺少需求能力的提供者，不调用旧预览分支。

`DescribeAsync` 打开 generation。generation 绑定配置 Kind、配置 ID／Revision、Folder ID／路径、固定输入身份／根路径／摘要、Partial 标记和缓存预算。不同世界可在这个 generation 内拥有各自的视图；瓦片身份还包括 WorldId、LayerId、原点、UnitsPerPixel、MaximumHeight、模式和状态覆盖开关。所有数值必须有限。Render 不能变更已登记瓦片的参数。

每个 Canvas 在绑定同一会话期间保留非空 `ViewId`。完整需求以有序 `Tiles` 表达优先级，并带正数 `Revision`；每个瓦片请求必须携带相同的 ViewId 和修订。一个 generation 最多登记 8 个视图身份，所有视图合计最多 256 个不同瓦片。释放视图仍保留其修订墓碑；需要新的视图身份集合时打开新 generation。

## 更新和调用顺序

一次更新完整替换一个视图的需求。较旧修订忽略；同修订、同有序内容幂等；同修订内容不同拒绝。空集合释放该视图需求。更新只修改有界内存状态，不扫描目录、不解码、不分配瓦片工作缓冲。提供者失败时 Runtime 不提交该修订。

Host 合并快速变化，只保留一个最新待发送需求和一个正在发送的需求。先等待最新需求应用，再发送 Render；空闲 Render 槽位按最近服务顺序轮询，避免细化任务饥饿。旧修订请求若仍属于该视图的最新需求，可以复用共享工作；被移出的请求按取消处理。未来修订或未登记视图的 Render 拒绝启动计算。

多个视图的相同瓦片共享进度。单次 Render 取消只结束该调用；最后一个视图移除需求才取消共享任务。队列只持轻量描述，等待工作立即返回 `Unknown / IsFinal=false` 占位结果。提供者在分配前预留工作集，活跃工作不能被样本缓存逐出，活跃数量不超过 4。最低工作集超过预算时返回终止性诊断，内容状态仍为 Unknown。

关闭／切换来源时，Host 发送释放需求、取消并排空在途调用，然后关闭 generation。关闭释放所有视图及保留预算，不以闲置超时推断离屏。Runtime 保留关闭墓碑至插件停用；迟到更新、Render 和 Describe 不得重建 generation。插件停用前先排空其租约。

## 输出和内存

栅格固定为 256×256、预乘 BGRA。Runtime 冻结输出，调用方不得依赖提供者缓冲的后续修改。队列元数据、共享工作、保留 header、样本和栅格均进入代内账本；返回栅格、Runtime 副本及解码的有界瞬时分配须另行测量。工作完成后进入可逐出缓存仍然计账。

统计、诊断与绘制采用相同的瓦片相交规则，计数前排除视野外 chunk；负坐标采用向下取整的区块／region 划分。未知、无数据、无可见表面和读取失败不可互相代替。导航返回可选诊断，Host 显示其本地化提示。
